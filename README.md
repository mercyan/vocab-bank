# 词库 Vocab Bank — student copy

A static, public, no-sign-in vocabulary bank for **Chinese 2 + 3** (Santa Fe College).
Browse taught words, filter by level (中文二 / 中文三 / 通用) and lesson, search, and run
课前复习 warm-up flashcards. Students can add their own words — those save only in that
student's browser (localStorage), nobody else sees them.

**Live page:** https://mercyan.github.io/vocab-bank/

Single self-contained file: `index.html`. The taught words are baked into the `SEED`
array. To refresh after teaching more, update `SEED` and push; students' own added words
survive. Snapshot taken 2026-09-08 (60 words).
